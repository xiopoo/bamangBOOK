# 电子书改版方案：回归「原典汇编」

> 执行状态：已于 2026-08-08 按“保留书名、只收第一手署名文献”的口径落地。巴菲特卷收录合伙人信与伯克希尔致股东信；芒格卷收录官方 Wesco 致股东信。生成脚本为 `scripts/build-original-compendia.mjs`。

## 一、问题诊断

当前 `build_books/buffett_body.typ` 与 `munger_body.typ` 是**带编者框架的二次创作书稿**，不是原文汇编。

证据（以 `buffett_body.typ` 第 1–60 行为例）：
- 结构件 `#part_lead[...]`（篇导读）、`#quote(block: true)[核心问题/核心命题]`、`本章小结`、`#endnote_mark`、`#link` 互引，均为编者搭建。
- 每引一句巴菲特原话（`#quote` 块）后，紧跟大段**编者自己的解读/转述**（如"这句话很短，却改变了证券分析问题的顺序""这正是…的全部含义"），这些不是巴菲特写的。
- 两册还把巴菲特、芒格内容相互杂糅引用，偏离"各看各的原典"。

用户本意：要的是**纯原文汇编**——巴菲特的原话归《巴菲特文集》、芒格的原话归《芒格文集》，不加任何编者按语、导读、改写、解读，以此直接读原典。

## 二、目标形态

1. 仍为**两册**，互不重复：
   - 《巴菲特文集》= 巴菲特本人的原典文字集合
   - 《芒格文集》= 芒格本人的原典文字集合
2. **纯原文拼接**：保留两位先生原文完整，不做任何增删、改写、观点加工。
3. **零编者文字**：删除所有 `part_lead`、篇/章导读、`核心问题/核心命题` 框、本章小结、`#endnote` 解读、`#link` 互引、以及所有编者夹叙（如"这句话…""这正是…"）。
4. 仅以**筛选与归类**（分篇/分章的标题层级）体现编排思路，标题本身只是原文出处/主题的索引，不含观点。

## 三、原典素材清单（来自 `content/`，均为干净原典）

### 《巴菲特文集》素材
- `content/letters/` — 巴菲特致伯克希尔股东信（1965 起，按年）
- `content/partnership/` — 巴菲特合伙期致合伙人信（1957–1969）及合伙协议
- `content/articles/buffett/` — 巴菲特署名文章
- `content/talks/` — 巴菲特演讲（太阳谷、马里兰大学、北大光华等）
- `content/interviews/` — 巴菲特专访（CNBC、慈善捐赠、苏珊·巴菲特等）
- `content/qa/` — 伯克希尔股东大会文字记录（含巴菲特作答部分）
- `content/buffett-quotes/` — 若保留，仅作引文索引，**不附加解读**

### 《芒格文集》素材
- `content/munger-archive/` — 芒格档案（投资哲学、Daily Journal、书单、家族、mental-models 等）
- `content/munger-originals/` — 芒格原始文字（Wesco 致股东信 1997–2002 等）
- `content/poor-charlies-almanack/` — 《穷查理宝典》原典章节
- `content/articles/munger/` — 芒格署名文章
- `content/qa/` — Wesco 股东大会记录（含芒格作答部分）
- `content/talks/`、`content/interviews/` 中归属芒格的篇目

> 说明：`content/qa/`、`content/talks/`、`content/interviews/` 中两人同场的内容，按说话人归册；无法干净拆分者，优先归入各自主册并在文中标明发言人，避免跨册重复。

## 四、改造步骤

1. **备份现有书稿**：将 `buffett_body.typ` / `munger_body.typ` 移入 `build_books/_archive/`，保留可追溯（不删除，便于回滚）。
2. **重建 body 文件**：
   - 新建 `buffett_body.typ`、`munger_body.typ`，仅由 `#import` 公共件 + 原文 `#include` 或原文粘贴组成。
   - 原文以 `content/` 下对应 md 为源，**逐篇原样引入**，仅加最低限度的分篇/分章标题（标题文字为原文出处或主题索引，不含编者观点）。
   - 删除所有编者框架标记与夹叙。
3. **统一样式**：沿用 `book_common.typ` 的版式（字体、页边、标题层级），但去掉 `#part_lead` / `#endnote` 的渲染调用，确保编译通过。
4. **重新生成封面与预览图**：若书名/卷次无变化则沿用现有 `public/ebook-covers`、`public/ebook-previews`；若更名则同步更新（见下）。
5. **编译验证**：`typst compile` 两册 PDF，确认无报错、页数合理、无残留编者文字。

## 六、验收标准

- 两册 PDF 中**检索不到任何编者夹叙**（无"这正是""这句话改变了""核心命题"等表述）。
- 所有 `#part_lead` / `#endnote` / `#link` 调用已移除，编译干净。
- 两册文章集合互不重复，各自均为对应作者原典。
- 原文内容逐字保留，无改写、无删节（仅做必要排版标题）。
