# 复利书房前端重构 Spec：视觉气质与信息架构

## 1. 文档信息

- **状态**：待评审、待执行
- **版本**：v1.0
- **日期**：2026-08-14
- **技术约束**：锁定 Next.js 14 App Router + React 18 + TypeScript + Tailwind，不迁移框架
- **设计基准**：Mungerisms（mungerisms.com）的档案编辑气质；不照搬其英文排版尺度与单人物架构
- **配套文档**：《复利书房成熟商业阅读网站重构Spec》（v2.0）为工程基线。本文件只规定**视觉气质**与**信息架构**两层；数据 schema、CSS 收敛方法、SEO、可访问性、性能验收均沿用重构 Spec 相应章节
- **范围**：导航、首页、目录页、详情页、专题页、博客页的视觉与结构
- **不在本期范围**：更换品牌色、重新翻译内容、重新制作 PDF、接入支付账户

## 2. 背景与问题结论

### 2.1 视觉问题

当前页面视觉是一套「博客门户」语言，与「长期投资阅读档案馆」的定位不匹配：

1. 首页出现 emoji 图标（🥤🛡️⭕🎢⚙️❓）、胶囊按钮（`border-radius: 999px`）、双列卡片网格，气质偏工具站；
2. 首页首屏是「最新文章」，传达的信息是"这里在更新博客"，不是"这里保存了一套档案"；
3. 样式语言分裂：`archive-*` 类、Tailwind 原子类、CSS Module 三种并存，同站不同页气质不一致；
4. 卡片依赖边框 + 阴影分层，缺少发丝线与留白带来的纸感；
5. `--archive-gold` 金色在标题编号、角标等处大面积出现，金色一旦多用，档案感被营销感替代。

### 2.2 内容组织问题

1. 当前导航为「博客 / 原典 / 研究 / 资料库」四组，与重构 Spec §5.1 定稿的「原典档案 / 公司研究 / 阅读路径 / 关于」不一致，两套结构并存造成混乱；
2. 首页堆叠了博客、本周推荐、人物、专题、搜索五个入口，没有回答"网站是什么、今天读什么、为什么可信"；
3. 博客、公司研究、投资概念、思维模型等入口职责边界不清，用户不知道从哪里开始。

### 2.3 结论

前端重构以**去博客化、档案化、编辑化**为总方向：

- 首页不再以「最新文章」开头，改为档案首屏；
- 导航回到重构 Spec 定稿的四栏目；
- 视觉以字体层级、留白、发丝线为主，去除 emoji、胶囊按钮、卡片阴影；
- 品牌色保留（赭红 + 羊皮纸 + 墨），通过使用策略调整气质，不换色。

## 3. 视觉气质

### 3.1 关键词

**安静、可信、档案馆、长期阅读、克制商业化。**

气质来源：字体层级 + 留白 + 细分隔线 + 纸张色/墨色/低饱和强调色。不依赖卡片堆、渐变、统计图标和装饰背景。

### 3.2 保留清单（品牌资产，不动）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--archive-oxblood` | `#AB1942` | 品牌赭红：链接、强调、kicker |
| `--archive-paper` | `#F7F2E7` | 羊皮纸底色 |
| `--archive-ink` | `#211D16` | 墨色：标题、正文 |
| `--archive-ink-soft/faint` | `#4C4537` / `#665D4B` | 次级文字 |
| 深色模式 | `#17140F` / `#F1EADA` | 深色底 / 深色字 |
| `--archive-serif` / `--archive-sans` | Noto Serif SC / Noto Sans SC | 标题衬线 / UI 无衬线 |

### 3.3 降权清单（改变气质的关键）

| 项 | 现状 | 改为 |
|---|---|---|
| `--archive-gold` `#9A7A37` | 标题编号、角标、花饰大面积使用 | 仅允许：发丝装饰线、分隔符、小号编号（≤0.78rem 场景用 `--archive-gold-deep` `#87662C` 保证 AA） |
| 胶囊按钮 | `border-radius: 999px` 的 `archive-home__hero-btn` | 方角（`2px`）或微圆（`--archive-radius`），全站按钮形状统一 |
| 卡片边框+阴影 | `archive-home__weekly-card` 等 | 区块间用 `border-bottom: 1px solid var(--archive-hairline)` 分隔，替代逐卡片描边 |
| emoji 图标 | 专题入口 🥤🛡️⭕ 等 | 全部替换为 lucide-react 线描图标（现有依赖）或纯文字 |
| 白色/灰底卡片 | 部分页面用白底卡片分层 | 统一纸色底，用发丝线分层 |

### 3.4 排版规范

- H1 支持显式语义换行，不允许单字孤行（沿用重构 Spec §9.3）；
- 标题/引语：衬线，标题字距 `-0.03em ~ -0.05em`；
- 正文：阅读层保持 serif，行高 `1.8—1.85`（桌面）、`1.85—1.9`（移动）；
- 元数据/年份/导航/按钮：无衬线，`white-space: nowrap`，避免数字与英文断行；
- 年份数字使用表格数字（tabular-nums），档案时间轴对齐；
- 标点不得单独出现在行首。

### 3.5 三层密度（沿用重构 Spec §9.2）

| 层级 | 页面 | 规则 |
|---|---|---|
| 展示层 | 首页、专题页 | 少量重点、较大标题、明确编辑推荐 |
| 目录层 | 档案、列表、索引 | 紧凑、连续、可快速扫描 |
| 阅读层 | 信件、问答、研究详情 | 正文舒适、元数据克制、工具稳定 |

### 3.6 尺寸与间距

- 目录页最大宽度：`72rem`；正文宽度：`39—44em`；
- 首页展示区块间距：`2.5—3rem`；专题页区块间距：`2.5rem`；目录区块间距：`1.5—2rem`；
- 首页区块之间用 `border-bottom: 1px solid var(--archive-hairline)` 分隔；
- 首屏不得用无理由 `min-height` 制造大块空白。

## 4. 信息架构

### 4.1 一级导航（与重构 Spec §5.1 对齐，取代当前「博客/原典/研究/资料库」）

```text
原典档案
公司研究
阅读路径
关于
```

全站搜索、主题切换为工具入口，不占用内容栏目位。博客退到二级，不再是一级栏目。

### 4.2 二级结构（沿用重构 Spec §5.2）

```text
原典档案
├── 总览
├── 巴菲特
├── 芒格
├── 段永平
├── 信件（股东信 / 合伙人信）
└── 问答与演讲

公司研究
├── 深度研究
├── 公司索引
└── 商业主题

阅读路径
├── 新读者从这里开始
├── 巴菲特阅读路径
├── 芒格阅读路径
├── 段永平阅读路径
└── 主题阅读

关于
├── 关于复利书房
├── 来源与编辑原则
├── 修订记录
└── 联系与纠错
```

### 4.3 博客的处理

- `/blog` 保留为独立目录页，使用目录页模板；
- 博客不再出现在首页首屏与一级导航；
- 公司研究、投资概念、思维模型等解读内容归入「公司研究」与对应专题，不与博客混层。

### 4.4 URL 与迁移

- 现有内容路由（`/buffett`、`/munger`、`/duanyongping`、`/letters`、`/partnership`、`/qa`、`/talks`、`/business-history`、`/companies`、`/concepts`、`/model`、`/blog` 等）保持不变，只调整导航归属与首页链接；
- 新增 `/archive` 作为「原典档案总览」（可选用，若落地则接管当前 `ThinkerArchivePage` 总览入口）；
- 任何改动的旧 URL 通过 301 迁移表处理，不允许新旧并存返回 200 正文。

## 5. 首页模板（去博客化）

### 5.1 模块顺序

首页不是完整目录，也不是博客流。按以下顺序组织（Mungerisms 首屏模式 + 重构 Spec §7.1）：

1. **品牌首屏**
   - kicker：`长期投资阅读档案馆`（赭红小字，字距 0.14em）
   - H1：`复利书房`
   - 一句话承诺（≤90 汉字）：说明内容范围与整理原则
   - 一句档案题词（可选）：来自巴菲特/芒格原典的短引语（对应 Mungerisms 首页引语位）
   - 主动作：`开始阅读`（进入 `/archive` 或 `/buffett`）
   - 次级链接：`了解整理方法`（进入 `/about/editorial`）
2. **编辑者说明**（对应 Mungerisms "Note from the Editor"）
   - 3—4 行，说明"这里保存什么、以什么原则整理、目前完整到什么程度"
   - 落在首屏之下，字数不超过 160 汉字
3. **今日推荐**
   - 一条编辑精选内容：年份、类型、阅读时长、状态 + 80—160 字推荐理由
   - 由显式配置产生（沿用重构 Spec §11.1 的 `HomepageRecommendation`），不取数组第一项
4. **档案抽屉**
   - 巴菲特 / 芒格 / 段永平 / 信件 / 问答与演讲 / 公司研究
   - 每个抽屉：标题 + 一句用途说明 + 数量（条数由数据计算）
   - 用发丝线分隔的连续列表，不用卡片
5. **从这里开始**
   - 2—3 条皇冠阅读路径（重构 Spec §11.2）
6. **最近修订**
   - 3—6 条，按 `updatedAt` 排序，显示修订日期与状态（重构 Spec §11.3）
7. **编辑说明**
   - 来源、翻译、校对、完整度、纠错原则（文字块 + 纠错入口）
8. **低干扰产品入口**
   - 仅说明文集适合连续阅读，不使用抢夺首屏注意力的购买按钮

### 5.2 硬性约束

- 首屏只有一个 H1、一个主要按钮；
- 390px 下 H1 无单字孤行；
- 首次滚动一屏内出现可点击内容；
- 不出现"最新文章"博客流模块；
- 不出现 emoji 图标与胶囊按钮；
- 所有链接通过统一路由函数生成，杜绝 `/undefined`；
- 今日推荐配置缺失时构建失败或回退到已验证皇冠内容，不得生成空链接。

## 6. 目录 / 详情 / 专题模板

### 6.1 目录页

沿用重构 Spec §7.2：面包屑 → 页标题与编辑说明 → 紧凑统计条 → 筛选与排序 → 连续列表 → 分页/分年折叠 → 目录说明。

视觉调整：列表行用发丝线分隔；行内元数据（人物 · 类型 · 阅读时长 · 状态）无衬线小字；状态标签带文本不单靠颜色；`ArchiveList` 为唯一列表组件，禁止卡片与表格混用。

### 6.2 详情页

沿用重构 Spec §7.3：面包屑 → 标题副题 → 阅读元数据 → 可信度摘要 → 阅读工具 → 正文 → 章节目录 → 来源与编辑说明 → 上一篇/下一篇 → 相关阅读 → 纠错入口。

视觉调整：详情页不渲染 emoji；来源说明（`SourceNote`）统一为发丝线框住的文字块，不使用彩色背景块。

### 6.3 专题页

沿用重构 Spec §7.4：专题定位 → 为什么值得读 → 推荐阅读顺序 → 主要资料入口 → 皇冠内容 → 最近修订 → 延伸内容。

视觉调整：专题页标题区采用展示层排版（大衬线标题 + kicker），与目录层明显区分。

### 6.4 博客目录页

`/blog` 使用目录页模板：页标题与编辑说明 → 按时间倒序的连续列表（标题 + 一句说明 + 日期 + 阅读时长）。不使用双列卡片网格。

### 7.2 样式分层

沿用重构 Spec §10.1 的目标结构：

```text
src/styles/
├── tokens.css        # 设计令牌（从 globals.css 迁移，颜色/字号/间距/圆角/发丝线）
├── reset.css
├── typography.css    # 标题/正文/元数据排版 + 中文断行规则
├── utilities.css
├── components/       # header / footer / archive-list / metadata / source-note / ...
└── templates/        # home / catalog / article / topic
```

迁移规则（沿用重构 Spec §10.2）：

- `globals.css` 收敛为令牌 + reset + 真正全局规则；
- 首页样式从 `home.css` 迁移到 `templates/home.css`，删除胶囊按钮、emoji 相关规则；
- `reading.css` 保留为阅读层样式，但字号/颜色令牌统一引用 `tokens.css`；
- 页面不再新增独立 `.module.css` 承载视觉类（交互局部状态除外）；
- 禁止新增 `!important`；已有 `!important` 在迁移到的组件时删除；
- Tailwind 只保留布局与少量原子能力，品牌视觉使用令牌。

### 7.3 导航交互

沿用重构 Spec §5.3：桌面端一级标签单行、下拉最多两列、键盘可用（Enter/Space/方向键/Tab/Escape/点击外部关闭）、`aria-expanded` 等属性一致、移动菜单锁定背景滚动、触控目标 ≥44×44px。

## 8. 迁移顺序

```text
第 1 步  导航重构：SiteHeader/MobileNavigation 改为四栏目（博客退级）
第 2 步  首页重构：去博客化，落地品牌首屏 + 编辑者说明 + 今日推荐 + 档案抽屉 + 皇冠路径 + 最近修订 + 编辑说明
第 3 步  博客目录页改用统一目录模板
第 4 步  目录页与详情页视觉收敛（发丝线、去 emoji、按钮统一、SourceNote 样式）
第 5 步  专题页展示层排版
第 6 步  CSS 分层迁移与清理（tokens.css 抽取、home.css 收编、删除遗留规则）
第 7 步  响应式矩阵 + 深浅模式 + 验收
```

每步独立可交付、可回滚，不与内容数据迁移混在一个提交中。

## 9. 验收标准

### 9.1 视觉验收

- 首页无 emoji 图标、无胶囊按钮、无"最新文章"博客流；
- 首页与目录、详情、专题明显属于同一网站（同一套令牌与发丝线语言）；
- 金色仅出现在装饰位，小号功能性文字使用 `--archive-gold-deep`；
- 页面无无内容的大块固定高度空白；
- 深浅色模式均保持可读，主题切换无闪烁。

### 9.2 结构验收

- 一级导航为「原典档案 / 公司研究 / 阅读路径 / 关于」，博客不在其中；
- 首页首屏回答"网站是什么、今天读什么、为什么可信"；
- 核心原典最多两次点击到达；
- 博客作为目录页存在，不再承担首页入口。

### 9.3 工程验收

- `npm run build` 成功，无新增 TypeScript 错误；
- 首页与导航链接全部返回 200，无 `/undefined`；
- 无新增 `!important`；
- `globals.css` 收敛为令牌 + reset + 全局规则；
- 关键视口（320/390/768/1024/1280/1440）无横向溢出、导航单行、H1 无单字孤行；
- 键盘可操作导航与菜单，Escape 可关闭并恢复焦点。

## 10. 发布门禁

以下任一条件存在时不得发布：

- 首页出现 emoji、胶囊按钮或博客流模块；
- 导航仍含"博客"一级栏目；
- 首页任何链接 404 或 `/undefined`；
- 构建失败；
- 关键视口导航断行或横向溢出；
- 新增临时 CSS 覆盖规则或 `!important`。
