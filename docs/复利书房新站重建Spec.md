# 复利书房新站重建 Spec

## 1. 决策与目标

### 1.1 已确认的决策

复利书房采用“**内容资产保留、产品前台重建**”的方式推进。

- 不继续以现有页面、样式和路由为基础持续修补；
- 保留现有 Markdown、音频、图片、原始出处、已校对文本及必要的内容解析能力；
- 新站以一套统一的内容目录、URL 规则、阅读模板和视觉系统重新建立；
- 旧站在新站上线前冻结，只处理会造成内容损失或访问中断的故障；新站完成验收并切换后，旧站整体下线。

### 1.2 产品定位

> 复利书房是一个以巴菲特、芒格和段永平原始资料为核心，延伸到公司研究、商业史、长期价值投资写作者文章与主题文集的中文价值投资阅读档案馆。

新用户应在首页十秒内知道：这里收录谁、可以从哪里读起、资料来自哪里，以及如何购买电子文集。

### 1.3 本期成功标准

1. 读者可以按人物、资料类型、年份和关键词找到资料；
2. 任意正文页的来源、年份、资料类型和上下文关系清楚可见；
3. 三位核心人物和四位博主均有完整、稳定的入口；
4. 电子书是清楚但不打扰阅读的独立商业入口；
5. 旧站已有公开链接可以被重定向到新站对应页面，无法一一对应时至少落到正确目录。

## 2. 内容范围

### 2.1 核心人物档案

| 人物 | 栏目 | 当前资产 | 新站呈现 |
| --- | --- | --- | --- |
| 巴菲特 | 合伙人信、股东信、演讲、访谈、股东大会实录 | 信件、演讲、访谈、问答资料 | 人物首页 + 五类目录 + 统一阅读页 |
| 芒格 | 西科（Wesco）股东信、每日期刊（Daily Journal）股东信、《穷查理宝典》、有声书、思维模型 | 西科与每日期刊资料、原始演讲、《穷查理宝典》、音频、模型 | 人物首页 + 专题目录 + 统一阅读/聆听页 |
| 段永平 | 问答录、网易博客 | 问答与博客资料 | 人物首页 + 两类目录 + 统一阅读页 |

### 2.2 四位博主

四位博主文章作为“投资写作”板块，不与三位核心人物原典混为同一层级：

1. 唐僧的碎碎念；
2. 在苍茫中传灯；
3. 方伟看十年；
4. 梁孝永康。

四位博主文章全部迁移。每位博主应有个人归档页，支持按年份、标签和文章标题浏览；文章页保留原文链接与转载说明。

### 2.3 电子书

电子书作为独立的“文集”栏目，首期至少覆盖《巴菲特文集》与《芒格文集》。每个商品页明确展示：适读对象、内容范围、目录样章、版本、价格、人工购买方式、售后与来源说明。

首期不接入在线支付、自动交付、登录、账户或订单系统；购买通过人工方式完成，并在页面上清楚说明。

### 2.4 研究延伸

公司研究与商业史全量进入新站，作为“研究资料”板块，与原典档案保持清晰的层级差异：它们帮助读者理解企业、行业与资本配置，但不与三位核心人物原典混为同一资料类型。

### 2.5 明确不纳入首期能力

- 未完成的登录、账户、订单中心和真实支付能力；
- 尚未完成来源与版权核验的内容；
- 内部编辑文档、构建文件、原始文件名和临时校样。

上述内容不作为新站公开功能或内容呈现；旧站下线后，内部资料仍在内容库中保留。

## 3. 信息架构

### 3.1 一级导航

```text
首页 | 原典档案 | 研究资料 | 投资写作 | 电子书 | 搜索 | 关于
```

其中“原典档案”展开巴菲特、芒格、段永平；“研究资料”展开公司研究与商业史；“投资写作”展开四位博主。移动端使用同一结构的抽屉菜单，不将二级栏目堆入首页。

正文使用稳定 ID 或编辑 slug；公开 URL 不得出现内部文件名、扩展名、重复编码或编辑状态。

## 4. 页面规格

### 4.1 首页

首页只承担导览与编辑选择，不承担完整目录。

1. 一句话说明资料范围与编辑原则；
2. 三位核心人物入口；
3. 一条“今日选读”，由编辑配置，并说明推荐原因；
4. 四位博主的近期精选；
5. 公司研究与商业史的编辑入口；
6. 两本电子文集入口；
7. 来源、修订与纠错说明；
8. 搜索入口。

### 4.2 人物首页

每位人物页包含：人物与档案范围说明、资料类型卡片、从哪里开始读、按时间阅读入口、编辑精选和资料来源说明。人物页不直接铺满全部文章。

### 4.3 目录页

所有目录页采用同一信息密度与筛选规则：

- 标题、简介与收录范围；
- 筛选：年份、资料类型、主题（仅在数据完整时显示）；
- 每条资料展示标题、年份、类型、阅读时长、来源/整理状态、一句价值说明；
- 排序优先为“推荐 / 时间顺序”，不使用含义模糊的“最近更新”。

### 4.4 阅读页

阅读页是全站最重要的模板，固定包含：

- 面包屑；
- 标题、人物、年份、类型、阅读时长；
- 来源、译校/整理、完整度、最近修订；
- 目录与阅读进度；
- 正文；
- 同类上一篇/下一篇与相关资料；
- 纠错反馈入口。

音频内容在同一模板中加入播放器、章节与文本对应关系，不另做风格割裂的页面。

### 4.5 博主与电子书页

- 博主页强调作者、文章时间线、标签和原文出处；
- 电子书页强调内容价值、目录与人工购买方式，购买按钮不出现在原典阅读页正文中；
- 首期固定使用人工购买入口，不接入或展示在线支付、自动交付、登录、账户和订单中心。

## 5. 内容数据契约

新站先建立一个统一内容索引；现有目录结构可以继续存在，但页面不得分别猜测文件名或拼接 URL。

每条内容至少具有以下字段：

```ts
type ArchiveItem = {
  id: string
  slug: string
  title: string
  person: 'buffett' | 'munger' | 'duan-yongping' | 'writer'
  writer?: string
  collection: string
  kind: string
  year?: number
  publishedAt?: string
  sourceUrl?: string
  sourceLabel?: string
  editorialStatus: '原文' | '译文' | '编辑整理' | '已校对' | '待核对'
  completeness: '完整' | '部分' | '未知'
  readingMinutes?: number
  summary?: string
  canonicalPath: string
  legacyPaths?: string[]
}
```

数据规则：

- 目录页、静态路由、站内搜索和上一篇/下一篇全部读取同一份索引；
- `id` 永不因改标题而改变；
- 不用文件名代替标题、slug 或 URL；
- 无法确认的来源、日期和完整度必须显示“待核对”，不可伪造；
- 同一正文只保留一个 canonical URL，旧链接以重定向表处理。

## 6. 设计原则

视觉方向为安静、可信、适合长读的中文档案馆，而不是金融资讯门户或课程销售页。

### 6.1 品牌识别

新站继续使用 **AB 1942（`#AB1942`）** 作为复利书房的主品牌色。现有 Logo、图标和品牌辨识不因重建而更换。

- 浅色模式以 `#AB1942` 用于主操作、当前导航、正文链接、重点标记与进度状态；
- 深色模式使用通过对比度校验的提亮变体，不直接以深红压在深色背景上；
- 纸张色、墨色和中性灰承担大部分页面面积，AB 1942 只用于建立识别与阅读层级；
- 不引入第二个竞争性的主品牌色；金色等色彩仅可作为低权重辅助色，不能替代 AB 1942；
- 所有组件从同一组设计变量读取品牌色，禁止在页面中散落硬编码的近似红色。

- 用强层级、留白和排版建立秩序，避免重装饰；
- 主阅读列控制在舒适行宽，中文标题按语义断行；
- 目录用可扫读的紧凑列表，首页用较舒展的编辑模块；
- 支持深色模式、字体调节、阅读进度和移动端连续阅读；
- 颜色用于内容状态和操作反馈，不作为分类的唯一方式；
- 全站组件、卡片、标签、元数据和页脚只有一套规范。

## 7. 重建策略

### 7.1 保留与替换

| 保留 | 替换 |
| --- | --- |
| 内容文件、音频、图片、原始出处、已有校对成果 | 首页、导航、页面布局、样式体系 |
| 可验证的内容解析与搜索能力 | 分散的内容读取逻辑与 URL 拼接 |
| 已公开的 URL 清单 | 旧路由结构与重复页面 |
| 电子书内容与商品资料 | 未完成账户、订单和支付界面 |

### 7.2 实施阶段

**Phase 0：冻结与备份**

- 建立旧站快照、现有 URL 清单和访问数据备份；
- 停止向旧前台新增栏目；
- 明确所有未提交改动的归属，避免重建覆盖现有编辑工作。

**Phase 1：内容盘点与统一索引**

- 按本 Spec 的范围生成内容总表；
- 清理标题、年份、来源、人物归属和重复项；
- 建立公开 URL 与旧 URL 映射；
- 抽样核验核心资料是否能正常打开与显示。

**Phase 2：新站骨架与模板**

- 建立全局导航、页脚、搜索、人物页、目录页和阅读页；
- 先用少量真实内容完成端到端验证；
- 完成手机端与桌面端的基础阅读体验。

**Phase 3：核心档案迁移**

- 依序接入巴菲特、芒格、段永平；
- 为《穷查理宝典》与有声书完成专用但一致的阅读/聆听体验；
- 上线旧链接重定向。

**Phase 4：研究资料、博主与电子书**

- 接入公司研究与商业史，并与原典档案区分资料类型和编辑说明；
- 接入四位博主文章归档；
- 完成电子书目录、商品详情、人工购买与售后说明；
- 不建设支付、自动交付、登录、账户或订单能力。

**Phase 5：上线验收**

- 检查全部导航、筛选、搜索、详情页、移动菜单和旧链接；
- 进行来源与完整度抽检；
- 验证页面标题、描述、canonical、站点地图与性能；
- 新旧切换后保留可回退机制。

## 8. 验收门槛

新站不得在以下任一事项未通过时替换旧站：

1. 三位人物首页、所有一级资料目录和四位博主入口均可访问；
2. 所有目录链接均能进入对应内容，不出现 `undefined`、文件名或 404；
3. 抽样正文页均显示清晰来源与内容状态；
4. 巴菲特、芒格、段永平三类核心资料至少各抽检 20 篇，文本、目录和相邻阅读正常；
5. 《穷查理宝典》文本与音频入口正常；
6. 手机端导航、筛选、阅读和字体控制可用；
7. 旧公开链接均有对应重定向或合理的目录落点；
8. 电子书页只提供人工购买方式，不出现支付、自动交付、登录、账户或订单承诺；
9. 公司研究与商业史在新站中均有稳定目录与详情入口；
10. 新站切换成功后旧站整体下线，保留新站的旧 URL 重定向能力。

## 9. 已确认的实施边界

1. 芒格股东信仅指西科（Wesco）与每日期刊（Daily Journal）的股东信，不纳入伯克希尔股东信；
2. 电子书仅展示与人工购买，首期不接入支付和自动交付；
3. 四位博主文章全部迁移；
4. 公司研究与商业史进入新站；
5. 新站完成验收并切换后，旧站整体下线。
