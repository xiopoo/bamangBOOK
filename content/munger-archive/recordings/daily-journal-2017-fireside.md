# 2017 年每日期刊大会后的炉边谈话

2017 年官方的每日期刊大会结束后，芒格没有离场。他与留下来的人坐下，又回答了将近两个小时的问题——文字记录是根据一段约一小时四十八分钟的录音整理而成。公司事务已经讲完，这更接近芒格的随性畅谈，而非正式陈述。

**为什么值得一看。** 炉边谈话的形式剔除了季度更新的填充内容，只留下处世智慧的内核。他描述了自己的阅读习惯（"我起床后会读三四份报纸……而且手头总有两三本正在读的书"），并指出，正是充分的准备让你在难得的机会出现时有胆量出手。其中还有一段典型的发挥，讲即便是占据主导地位的公司——杜邦、通用汽车、柯达、施乐——也会被超越，因为世界一直在变，护城河会被侵蚀。

**值得关注的话题：** 集中投资与"打孔卡"式的纪律；他为何拒绝与庄家对赌（"我不喜欢在胜算不利时下注"）；家庭、慈善，以及他如何看待充实的一生。可与[2017 年的正式大会](https://mungerarchive.com/zh/recordings/daily-journal-2017/)搭配观看，以了解一整天的全貌。
