# 李嘉诚原典 · 采集说明

本目录收集李嘉诚**亲身发言、亲笔撰写**的一手文字材料，仿照"巴菲特股东信 / 合伙人信 / 演讲 / 座谈"的归档思路，只收原典，不收二手加工的"语录"。

## 归档口径（与巴菲特文集一致）

- 收录对象限：本人演讲稿、年报主席报告书、访谈/座谈实录、声明与亲笔信。
- 身份分级：
  - `原话`：现场发言、亲身撰写的全文；
  - `实录`：媒体/机构整理的全文对话（如南方周末专访）；
  - `转录`：录音/视频转写（标注来源）；
  - 不收：未经原始出处的"金句合集"、营销号改写。
- 每个文件带 YAML frontmatter（见 `CONTENT_SCHEMA.md` 约定）：`content_type`、`source_url`、`author`、`published_at`、`verification` 等。
- `verification` 含义：`verified`（已对照原始发布）/ `partial`（可阅读但部分未核对）/ `pending`（待核验，不可作确定性引文）。

## 一手材料分级（抓取优先级）

1. **官方存档（最高优先）**：李嘉诚基金会 `lksf.org` 的 speeches / interviews 栏目；汕头大学官网 `stu.edu.cn` 演讲录；长江商学院 `ckgsb.edu.cn`。
2. **权威媒体全文**：南方周末、界面、金融界、中国新闻网、证券时报等对演讲/声明的全文发布。
3. **年报 PDF**：HKEX 披露易搜"长江实业/长江和记"年报，抽取"主席报告书"。
4. **汇编合集**：1990–2017 汕大演讲汇总、长江商学院系列整理（仅作索引线索，正文仍以官方为准）。

## 运行抓取

```bash
# 1) 先列出已知一手链接清单（不下载）
python3 scripts/crawl_likaching.py --list-seeds

# 2) 抓取官方存档（lksf.org 演讲+访谈栏目），自动落盘到对应子目录
python3 scripts/crawl_likaching.py --source lksf

# 3) 抓取源清单里已确认的具体 URL
python3 scripts/crawl_likaching.py --source seeds

# 4) 单条 URL 试抓（不落盘，仅打印元数据）
python3 scripts/crawl_likaching.py --url https://... --dry-run

# 5) 抓完生成/刷新索引
python3 scripts/crawl_likaching.py --build-index
```

依赖：`pip3 install requests beautifulsoup4 html2text`
