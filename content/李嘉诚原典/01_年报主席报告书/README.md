# 01_年报主席报告书

长江实业（1972 上市）至 长和 / 长实 历年年报中的"主席报告书"，相当于巴菲特的"股东信"。
李嘉诚掌舵期约 1950–2018，几乎每年一篇，谈经营哲学、周期、风险、现金与资本配置。

## 已归档（李嘉诚署名）

### 长江和记实业（CKH，00001.HK，2015 重组后实体）
来源：`https://doc.irasia.com/listco/hk/ckh/annual/<年>/tc/chairmanstatement.pdf`
- 2015 / 2016 / 2017 主席报告书（李嘉诚署名，2018-05 退休）

### 长江实业（集团）（0001.HK，2015 重组前实体）
来源：HKEXnews 披露易「董事会主席业务报告」 standalone 公告（繁体原文，pdfplumber + opencc 转简体）
- 2003 / 2004 / 2005 / 2006 / 2007 / 2008 / 2009 / 2010 / 2011 / 2012 / 2013 / 2014 主席报告书

每篇 frontmatter 均含 `source`（官方 PDF 直链）、`year`、`company`、`chairman: 李嘉诚`、
`published_at`（业绩公告日）、`verification: verified`。

## 备注
- 官方原文为繁体，本目录存简体版（frontmatter 标注 source 与转换方式），需繁体原貌可回源 PDF。
- 正文仅含「主席报告书/主席业务报告」章节（主席信函 + 管理层讨论与分析至雇员节止），
  已剔除企业管治、财务报表附注、核数师报告等其余内容。
