# 公众号通俗版（改写层）

本目录存放《所有者的眼光·巴菲特卷》的公众号连载稿，**与 `editorial/buffett/manuscript/` 书稿定稿分离**。

## 原则（不可违反）

1. **引用材料不变**：原档案、股东信、访谈中的原引文，以引用块形式保留，一字不改。
2. **核心命题不变**：每篇对应的章首核心命题原句保留。
3. **来源映射不变**：`[^b20x]`、B2-01~B2-09 等编号与用途不变。
4. **只改"讲法"**：过渡句、解释句、案例导语、小结、生活化类比，均为本目录新增，不进入书稿。

## 编辑风格（沿用已锁定规范，不再改动）

1. **引文格式**：原引文用 `**加粗标题：**` 引导 + 自然正文，不包引用块、不加井号。
2. **正文分段**：自然分段，不使用 markdown 井号标题（`#`/`##`/`###` 原样会显示，故全部去除，必要时用"一、二、三"中文序号作纯文字段落开头）。
3. **结尾署名**：文末用浅灰色、靠右对齐、破折线引导，标注发表时间与题目出处。格式沿用已确认样式，不擅自改。
4. **表格**：全部转为文字列表（公众号后台不解析 `|` 竖线表格）。

## 写作口径（内容要求，非格式）

1. **每篇独立成文**：不假设读者看过其他篇；开头点明本篇所讲的价值投资原则，案例自带完整背景（谁、哪年、什么买卖、结果），不引用"前面说过/下一章"。结尾不写承上启下的过渡。
2. **巴菲特风格**：口语化、像给合伙人写信；用日常类比（农场、棒球、合伙开餐厅）讲投资；坦诚自嘲、敢说"我也犯过错"；先把判断依据摊开让读者自己推，不硬塞结论；克制、不堆金句、不过度解释。

## 校验清单（每篇发布前对照）

- [ ] 所有原引文与书稿一字不差
- [ ] 所有 `[^b20x]` 引用与书稿一致
- [ ] 章首核心命题原句保留
- [ ] 没有新增任何虚构事实或虚构数字
- [ ] 不出现"上一章/前面说过/下一章"等跨篇依赖表述
- [ ] 结尾无指向后续章节的过渡句
