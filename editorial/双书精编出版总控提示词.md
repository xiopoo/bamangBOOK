## 五、两本书的独立定位

- 巴菲特如何理解股票、企业和市场？
- 他如何判断一家企业是否值得长期拥有？
- 如何理解内在价值、安全边际和所有者收益？
- 什么是优秀企业，护城河和定价权如何形成？
- 巴菲特如何判断管理层？
- 他如何进行收购、回购、分红和现金配置？
- 保险浮存金如何塑造伯克希尔？
- 巴菲特的投资方法如何从格雷厄姆式低估值演变为优质企业长期持有？
- 芒格、费雪和格雷厄姆分别如何影响他？
- 伯克希尔为何不仅是一家公司，也是一套制度？
- 普通读者可以学习什么，哪些做法不能简单模仿？

建议认知路径：

人物与时代

→ 内在价值  
→ 安全边际

→ 风险与错误

- 清晰；

- 以企业和案例为中心；
- 体现时间、复利与所有者责任；
- 避免成功学和财富崇拜。

### B.《理性的格栅》

定位：一部以多元思维模型、理性决策、商业判断和避免愚蠢为主线的芒格思想读本。

核心问题：

- 多元思维模型究竟是什么？
- 为什么知识需要形成格栅，而不是孤立记忆？
- 如何进行逆向思考？
- 为什么避免愚蠢往往比追求聪明更可靠？
- 如何理解能力圈、机会成本、概率和期望值？

- 多种心理倾向如何产生叠加效应？
- 激励机制为什么拥有超级力量？
- 芒格如何判断企业、管理层和投资机会？
- 芒格的思想如何用于学习、职业、关系和人生？
- 哪些模型是芒格明确提出的，哪些是后人扩展？

建议认知路径：

人物与精神坐标  
→ 理性训练  
→ 知识格栅  
→ 多元思维模型  
→ 逆向思考  
→ 能力圈  
→ 机会成本  
→ 概率与期望值  
→ 人类误判心理学  
→ 激励机制  
→ 商业判断  
→ 投资与资本配置  
→ 阅读、品格与人生  
→ 避免愚蠢的检查清单

编辑气质：

- 理性；

## 六、最高编辑原则

### 1. 忠于原意

不得为了表达流畅而改变人物原意。不得虚构观点、原话、故事、数据、时间、场景或人物关系。

### 2. 区分文字身份

必须明确区分：

- 巴菲特原话；
- 芒格原话；
- 原始文献；
- 编辑部转述；
- 编者导读；
- 背景说明；
- 延伸解释；
- 案例分析。

不得把编辑者的概括写成人物直接引语。

### 3. 来源可追溯

每条关键引文和重要事实至少记录：

- 来源文件；
- 原始标题；
- 人物；
- 时间；
- 场合；
- 原文；
- 当前译文；
- 在精编书稿中的位置；
- 可信度；
- 待核事项。

来源记录保存在项目内部，不需要链接到外部网站。

### 4. 不以“全部收录”为目标

将所有候选内容划分为：

- A 级：核心正文；
- B 级：案例、侧栏或延伸阅读；
- C 级：年表、附录、索引或资料版；
- D 级：当前不进入主书，但继续保留在完整资料典藏层；包括被主版本承接的重复稿、与主线弱相关的内容或暂缓使用的材料；
- E 级：需要人工确认。

每篇内容必须记录归类理由。

A—E 分级是编辑用途分层，不是版权判断、内容价值终审或删除清单。任何 D 级内容均不得物理删除；其中存在独立观点、案例、反例、思想变化或边界信息时，必须重新评估并安排到侧栏、附录、索引或典藏层。

### 5. 去重但保留思想演变

同一观点在不同材料中重复出现时：

- 选择最完整、最准确、语境最充分的版本作为主文；
- 同义重复内容合并或删除；
- 表述发生变化时整理为“思想演变”；
- 案例不同且具有解释价值时可以保留；
- 不得因机械去重而丢掉重要差异。

### 6. 保留人物差异

不得把两人的声音混成统一的“大师语录”。

巴菲特通常更侧重企业、管理层、股东关系、资本配置和长期持有；芒格通常更侧重思维模型、认知偏误、逆向判断、跨学科知识和理性训练。

### 7. 避免 AI 文风

禁止：

- 空洞拔高；
- 机械排比；
- 高频使用“不是……而是……”；
- 模板化转折；
- 无依据的赞美；
- 每节末尾强行升华；
- 把复杂思想压缩成成功学口号；
- 模仿人物口吻伪造金句。

语言应准确、自然、克制、有判断力。

### 8. 内容边界

本轮原则上只使用项目中已有的 Markdown 和内部原始文件。

允许：

- 在项目内部交叉核对版本；
- 使用项目中的英文原文校对中文；
- 使用现有 PDF 检查遗漏和版式；
- 在内部注释中保留来源文字。

如果确需外部核验，只能形成待核事项。未经确认，不得将外部新增内容写入正式书稿，更不得把外部链接写入成品。

## 十三、书内链接强制规范

这是不可妥协的硬性要求：

- `http://`
- `https://`
- `www.`
- 邮件链接；
- 社交媒体链接；
- 视频网站；
- 外部文章来源；
- 外部图片；
- 公众号跳转；

1. 保留有价值的链接文字；
2. 删除 URL；
3. 必要时改写为普通来源文字；
4. 若对应内容已收录本书，改为书内链接；
5. 若没有内部目标，保留为不可点击的来源文字；
6. 不生成空链接或伪内部链接。

### 3. 允许的内部链接

- 目录到篇、章、节；

- PDF 书签层级完整；
- 正文交叉引用可点击；
- 脚注与正文双向跳转；

- 无目标链接数；
- 重复 ID 数；
- 脚注返回异常数；
- 目录跳转异常数。

硬性结果：

- 外部链接：0；
- 空链接：0；
- 无目标链接：0；
- 重复 ID：0。
