# 段永平文集 · 主题分类规则说明

> 本文件定义全量单元（约 2860 个主语料单元）的主题分类判定规则，供分类子代理与质检统一执行。分类体系见 `00_taxonomy.json`。

## 0. 总原则

- 以主题为唯一组织原则，两级结构：卷（P1–P6）→ 章（Cx-y）。每单元必须归属**唯一**（卷，章）。
- 章内排序为逻辑序（由 `seq` 列实现）：**从原则到应用、从一般到具体、先核心论述后具体问答**。严禁按时间序。
- 分类以**单元内容**为准，不以标题关键词为准。需阅读正文后判定。

## 1. 六卷主题速查

| 卷 | 主题 | 典型内容 |
| --- | --- | --- |
| P1 | 投资理念 | 价值投资原理、能力圈、商业模式、估值、集中持仓、市场波动、风险、投资学习 |
| P2 | 公司与行业见解 | 苹果/腾讯/拼多多/茅台/OPPO 等具体公司与行业分析 |
| P3 | 企业管理与经营 | 企业文化、本分、消费者导向、产品、品牌、组织、战略、长期经营 |
| P4 | 人生哲学 | 平常心、诚信做人、快乐幸福、慈善、健康运动、人生选择 |
| P5 | 教育观点 | 给年轻人建议、学习方法、家庭教育 |
| P6 | 社会观察与公共话题 | 时事评论、宏观经济、纯第三方转载 |

## 2. 分类型判定规则

### 2.1 投资理念（P1）—— 核心判定
- 内容核心为**投资原则/方法论**（如何选股、何时买卖、如何看待市场、如何学投资）→ P1。
- 出现具体公司但**落脚点是投资原则**（如用茅台讲「商业模式第一」）→ 归 P1 相应章。
- 具体公司占主导（分析该公司该不该投、值多少钱、生意好不好）→ P2。

### 2.2 公司与行业见解（P2）
- 核心为**具体公司/行业的分析与判断** → P2 对应章节。
- 章内再按公司归类：C2-1 苹果/科技硬件；C2-2 腾讯/拼多多/网易/阿里/谷歌等互联网平台；C2-3 茅台/白酒/可乐/食品饮料；C2-4 OPPO/vivo/步步高/小天才/电子制造；C2-5 银行/保险/券商；C2-6 汽车/新能源（特斯拉/比亚迪/蔚来等）；C2-7 房地产/基建；C2-8 医药健康；C2-9 其他。
- 同时涉及多家公司、无从区分主次的行业讨论 → C2-9。

### 2.3 企业管理与经营（P3）
- 核心为**企业经营方法论**（本分、消费者导向、产品观、品牌、团队、战略决策、长期经营）→ P3。
- 企业文化是本编的核心；讲步步高/OPPO 的经营管理经验亦属 P3（而非 P2，除非落点是投资分析）。

### 2.4 人生哲学（P4）
- 核心为**个人心态与生活方式** → P4。
- C4-1 平常心（含「平常心是道」类）；C4-2 诚信道德做人；C4-3 快乐幸福财富观；C4-4 慈善公益；C4-5 健康运动生活（高尔夫/运动/体检等）；C4-6 面对成败与人生选择。

### 2.5 教育观点（P5）
- 核心为**对年轻人/学生/孩子的建议与教育** → P5。
- 浙大讲话、对学生的寄语、学习方法论、家庭教育（子女教育）→ P5。
- 注意与 P4 区分：讲「年轻人该怎么做人」若明显面向学生成长 → P5；泛论人生道理 → P4。

### 2.6 社会观察与公共话题（P6）
- 时事/社会现象评论、宏观政策经济 → C6-1/C6-2。
- **纯第三方转载**（标题「引用-」「转载-」且正文全部为第三方文本，无本人点评）→ C6-3。
- 转载中段永平附有实质点评/逐条回复 → 按内容主题归类（不入 C6-3）。

## 3. 长文单元（演讲/访谈/里程碑/speeches）

- 按**主导主题**归入对应卷章。
- 跨主题长文：归入覆盖最广的卷章；另登记到「长文篇目定位索引」。
- 例：步步高十周年讲话（企业文化）→ C3-1；浙大毕业生讲话（教育+人生）→ C5-1；万科财富人生对话（人生+投资）→ C4-3。

## 4. 章内逻辑排序（seq 赋值规则）

- 每章内按「先总论后分论、先原则后案例、先本人系统论述后具体问答」排 seq（1 起递增）。
- 同主题的问答聚合排列，避免时间跳跃造成割裂；同一讨论链路的条目相邻。
- seq 由分类子代理按阅读连贯性赋予；装配器严格按 (part, chapter, seq) 排序输出。

## 5. 质检要点

- 每单元 (part, chapter) 唯一；0 遗漏。
- 抽样抽查模糊单元（引用/转载、跨主题长文、公司×投资边界）判定一致性。
- 抽查章内 seq 无时间序倒灌（同主题讨论链路相邻即可）。
