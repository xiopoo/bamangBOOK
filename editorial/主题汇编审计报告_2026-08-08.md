# 《巴菲特文集》《芒格文集》主题汇编审计报告

日期：2026-08-08  
审计对象：`output/pdf/巴菲特文集_1956-2025.pdf`、`output/pdf/芒格文集_1924-2023.pdf`及其现有构建源  
目标版本：不改写文章正文，只按“所有者的眼光”和“理性的格栅”调整文章顺序，制作精致编辑汇编版。

## 一、审计结论

两本现有 PDF 的材料规模和资料价值是够的，主要问题不是缺材料，而是编排仍然以“资料类型”作为主线：人物、生平、合伙人信、股东信、年会、专题、演讲、模型，彼此分卷排列。

这种结构适合档案查找，不适合主题阅读。读者必须自己在数千页中寻找同一个问题在不同年份、不同场合的表达。

因此，新版本不应重写文章，也不应把文章改造成连续论述；正确做法是：

> 保留现有文章作为不可拆分的正文单元，为每篇文章建立主题标签和主归属，再按主题重新编卷、排序和制作索引。

## 三、当前版本的结构问题

### 1. 主线是资料类型，不是研究问题

例如巴菲特的“所有者关系”分散在合伙人信、1983 年股东信、1985 年访谈、股东大会问答和后期信件中；芒格的“多元模型”又分散在《穷查理宝典》、Wesco 问答、模型词条和访谈中。

现有版本把它们放在不同卷里，读者需要自行拼接思想演变。

### 2. 芒格模型卷的身份层级需要重新标识

232 篇模型内容约占芒格旧版字符数的 76.3%。这些文章有研究价值，但不能与芒格直接演讲和问答完全等同：

- 有些是芒格明确使用的模型；
- 有些是芒格反复引用的通用知识；
- 有些是站内编辑扩展或操作化解释。

新版本可以保留这些文章，但必须在目录和索引中显示材料身份，不能让排列方式制造“全部都是芒格原文”的错觉。

### 3. 现有构建流程并非严格的“正文不变”

旧脚本包含以下处理：

- 删除外部链接地址；
- 删除来源尾注、推广语和部分网页语法；
- 删除图像或改成图像占位；
- 删除重复标题；
- 对精确重复内容只保留一个版本；
- 芒格卷还会过滤专题站推广文字。

这些处理可以用于网站阅读版，但不符合本次“文章不改写、只调整顺序”的硬约束。新版本应保留每篇文章正文的稳定内容，只把元数据、目录和版式放在正文之外处理。

### 4. 不可拆分的综合现场文章不能强行归入单一主题

年度股东大会、Wesco 股东会和每日期刊年会通常一篇文章内包含多个主题。若把整篇文章按关键词硬塞进“估值”或“资本配置”，会造成新的错分。

本轮排序清单因此增加“综合现场与年度索引”位置：整篇文章保持完整，主题索引负责标记其中涉及的多个问题。只有在未来明确允许按问答单元拆分时，才把其中的单个问题分别编入主题正文。

## 四、新版本的编辑原则

### 正文层

文章正文不可改写、不可拼接、不可删段。允许的动作只有：

- 文章在卷册中的移动；
- 文章标题的目录化显示；
- 文章前的来源卡片；
- 页眉、页码、目录、书签和索引；
- 不改变正文意义的版式转换。

### 编排层

每篇文章设置一个“主归属主题”，避免同一篇文章反复出现。若一篇文章涉及多个主题：

- 正文只放在一个主主题中；
- 其他主题只在索引中建立交叉链接；
- 只有版本不同且具有独立信息时，才保留另一版本，并注明版本关系。

### 身份层

每篇文章在目录和索引中标明：

- 原始文献 / 访谈 / 年会问答 / 编译文章 / 模型词条 / 人物资料；
- 作者或讲话者；
- 年份与场合；
- 是否存在替代版本或重复版本。

## 六、去重和排序规则

1. 精确重复：只保留一个主版本；索引记录替代版本；
2. 同一演讲的不同译文：正文选择一个主版本，另一版本进入版本说明；
3. 同一主题的不同年份表达：原则上都保留，按“形成—成熟—晚年复述”排列；
4. 同一材料多主题：只设一个主归属，其他主题建立交叉索引；
5. 模型词条与原始演讲并存：模型词条不冒充人物原文，放在相应主题的“研究材料”位置；
6. 文章内容不因主题需要被截断、拼接或改写。

### 重复处理的新增硬规则

重复处理在主题排序之前完成，并建立独立台账：

- **精确重复**：正文规范化后哈希一致，只保留一个主版本；
- **同一演讲的重复译文**：选择出处清楚、上下文完整、文本稳定的主版本；其他版本不进入正文，但保留在版本台账；
- **同题异年或现场问答**：只要有新的事实、数字、案例、语境或思想变化，就不视为重复；
- **编辑汇编与原始材料重合**：原始材料优先，汇编版不再重复收入；
- **模型词条与人物原话重合**：人物原话优先，模型词条只在确有独立解释价值时保留；
- **无法确定是否重复**：暂不删除，标记为“待人工复核”，不以标题相似直接删稿。

每一条被排除的重复材料都记录：原路径、主版本路径、重复类型、规范化哈希、保留理由和是否存在独立增量。这样删掉的是正文重复，不是资料本身。
