# 700篇内容分级与身份判定说明

日期：2026-07-30  
范围：项目候选清单中的700篇Markdown，共8,887,885字符。  
明细：`内容分级表_700篇.csv`与同名JSON。

## 一、执行规则

1. 项目目录内全部Markdown均按已拥有本项目所需使用权处理。
2. 项目成品为内部、非公开PDF与EPUB；没有任何文件因缺少单独版权、翻译权或再出版授权证明而降为E级。
3. 内容级别只依据思想相关性、事实可信度、人物身份、文本质量、重复程度和结构价值。
4. “可用”与“可归因”为两件事。编辑扩展、二手概括和通用模型可以使用，但不能标成巴菲特或芒格原创。
5. 分级对象是候选文件的编辑用途，不等于整篇原样收入。A/B文件也可能只抽取观点、案例或一段可靠转录。
6. 不物理删除、不覆盖任何原始Markdown及旧版PDF、EPUB。

## 四、A—E级的编辑含义

### A级

可承担主书核心命题或关键证据。进入主书前仍须：

1. 核对原话、译文和场合；
2. 删除网页导航、重复导语和外部链接；
3. 处理同一命题的多次表达；
4. 补充边界和修正性表达。

### B级

优先拆取为案例、侧栏、场景、编者解释或延伸阅读。不因篇幅长而整篇收入，也不因是模型稿而自动归于芒格。

### C级

保留检索、年表、附录、索引和典藏价值。主书正文不承担其全部体量。

### D级

不进入当前主线，常见原因包括：与主版本精确重复、内容增量很低、偏离人物思想主线、已有更可靠材料。D级不等于删除。

### E级

只用于事实待核、内容身份不清、来源无法判断或必须人工确认的材料。版权授权文件是否单独存在不是E级理由。

## 六、篇幅控制的含义

A、B级总字符数远高于两卷正文控制线，所以第三阶段不能以“入选文件整篇拼接”方式生产正文。建议以观点原子为基本单元：

1. 巴菲特卷从A级约99.6万字符和B级案例中压缩到30万—36万字符；
2. 芒格卷从演讲、档案与模型素材中压缩到26万—32万字符；
3. 附录、索引和典藏层单独计量；
4. 每个正文单元只保留最成熟表达、必要的思想演变和有区分度的案例。

## 七、机器分级的使用边界

本表已经覆盖全部700篇并建立一致字段，但它是第二阶段的编辑工作底表，不是无需复核的最终目录。第三阶段应对A级全文、拟使用的B级片段、高归因风险条目以及同题异版执行人工复核。
