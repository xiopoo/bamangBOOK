# 第一章重编方案：巴菲特与芒格主题版

> 资料母版：`output/pdf/巴菲特文集_1956-2025.pdf` 与 `output/pdf/芒格文集_1924-2023.pdf`。本方案不把《所有者的眼光》《理性的格栅》当作资料母版；它们只提供主题方向。正文取材时回到两本大文集对应的原始文件核对。

## 共同编辑口径

- 类型：个人投资研究阅读版，不是商业教材，不是原件目录。
- 目标：读完第一章后，读者能够用自己的话说明这位作者的基本观察位置，并把它用于阅读企业材料。
- 原文比例：约 65%—75%；编者串联、背景和操作化说明约 25%—35%。实际以材料自然长度决定，不为凑比例硬切原文。
- 归属纪律：同一来源在本章承担一个主任务；跨章节只保留短引或书内指针，不重复整段。
- 章节长度：暂定每章 8,000—12,000 中文字，约 25—40 个 A4 电子阅读页；若材料需要，可以突破，不设硬页数。
- 章节结尾：保留一页“研究回看”，不写泛泛升华。

## A. 巴菲特第一章：股票背后是一家企业

### 核心问题

买入一只股票时，投资者究竟获得了什么？如果市场报价暂时消失，投资理由是否仍然成立？

### 本章只解决三件事

1. 股票是企业所有权的一部分，而不是报价器上的符号；
2. 市场价格是交易条件，不能代替对企业的理解；
3. 所有者视角会改变阅读企业、管理层和资本配置的顺序。

估值公式、所有者收益、护城河、经理人评价和资本配置方法分别留给后章，不在第一章提前讲完。

### 主材料

1. `content/articles/buffett/巴菲特谈投资_1985.md`
   - 任务：提供“拥有企业的一部分”“五年不开市”“先估值再看价格”“没有三振出局”等核心表达。
   - 身份：巴菲特访谈中文转录；访谈背景和编者导语必须与人物原话分开。
2. `content/letters/berkshire_1983-巴菲特致股东信.md`
   - 任务：展示“所有者合伙人 / 执行合伙人”如何从个人理念进入公司沟通。
   - 身份：巴菲特致股东信中文翻译。
3. `content/letters/berkshire_1985-巴菲特致股东信.md`
   - 任务：展示市场价格与内在商业价值、股东回报和发行政策的关系。
   - 身份：巴菲特致股东信中文翻译。
4. `content/partnership/partnership_1957-巴菲特致合伙人信.md`
   - 任务：作为早期对照材料，说明“把投资看成合伙经营”并非1980年代才出现。
   - 身份：巴菲特致合伙人信中文翻译；只选与所有者位置直接相关的段落。

### 建议结构

1. **开篇：先把股票还原成企业的一部分**
   - 以1985年访谈的一段完整引文开篇；
   - 编者只用两三段说明“观察位置”发生了什么变化。
2. **五年不开市：拿走转售机会后还剩什么**
   - 保留思想实验及其上下文；
   - 只补充一个投资研究应用：读年报时先看企业事实，再看报价。
3. **所有者要看哪些事实**
   - 只列四项：收入来源、资本需求、管理层、留存收益用途；
   - 每项配一个巴菲特原文片段，不在本章展开方法论。
4. **从个人判断到股东关系**
   - 1983年“所有者合伙人 / 执行合伙人”；
   - 1985年关于股价不应长期脱离内在价值的制度表达。
5. **投资研究中的使用边界**
   - 所有者视角不等于永远持有；
   - 不等于只买好公司；
   - 不等于忽略价格和流动性。
6. **研究回看**
   - 若五年不能卖出，我需要核对哪三项经营事实？
   - 哪些事实出现时，我会承认原判断失效？

### 明确删除或后移的内容

- 将“市场关闭测试”四问保留为编者工具，但不写成巴菲特原有的正式方法；
- 删除本章中对第二章 DCF、第三章所有者收益的提前教学；
- 删除重复的“不是 X，而是 Y”式总结；
- 将过长的“常见误解”压缩为一页；
- 不在第一章展开伯克希尔完整制度史。

### 预计产出

- 正文：约 9,000—11,000 字；
- 直接引文：6—9 段，均有来源和年份；
- 案例：不超过 2 个；
- 脚注：只解释出处和必要背景；
- 不另制复杂图表，先保证文字可以连续读完。

## B. 芒格第一章：一把锤子为什么不够

### 核心问题

为什么专业能力越强的人，反而可能更容易把所有问题都看成同一种问题？多元思维模型究竟是投资工具，还是阅读现实的基本条件？

### 本章只解决三件事

1. 单一学科或单一模型会系统性扭曲问题；
2. 多元模型的价值不在数量，而在于用不同机制交叉检查；
3. 投资研究必须先建立工具箱，再进入企业和价格。

模型清单、心理倾向、概率计算和人生品格分别留给后章，不在开篇全部展开。

### 主材料

1. `content/talks/芒格：南加大商学院演讲_1994.md`
   - 任务：提供“祖母的规矩”“铁锤人”“普世智慧先于选股”的原始现场。
   - 身份：芒格演讲中文整理；引文和整理者说明分开。
2. `content/munger-archive/recordings/usc-1994-worldly-wisdom.md`
   - 任务：与中文版本互校现场语气和段落顺序。
   - 身份：演讲档案转录 / 译文；只作为版本核对，不重复成第二篇正文。
3. `content/qa/Wesco_股东大会_1997.md`
   - 任务：补充“多个模型叠加”和企业判断中的实际使用。
   - 身份：Wesco 股东大会问答；只取与工具箱直接相关的问答。
4. `content/munger-archive/recordings/stanford-law-1996.md`（如文件名核验后存在）
   - 任务：作为跨学科方法的第二次公开表达，展示思想延续，不展开完整演讲。

### 建议结构

1. **开篇：芒格为什么先讲胡萝卜，不讲选股甜点**
   - 直接从1994年演讲的现场进入；
   - 不先写芒格生平，也不先列模型总表。
2. **铁锤人：单一工具怎样扭曲现实**
   - 保留铁锤谚语和脊椎按摩师例子；
   - 编者只解释“这不是知识少，而是把工具边界误当成现实边界”。
3. **专业能力的反面**
   - 用一个法律、会计或投资研究场景说明专长如何变成盲区；
   - 不连续堆叠多个现代行业类比。
4. **格栅不是模型清单**
   - 用1997年Wesco材料说明模型之间的交叉检查；
   - 明确区分芒格原话、通用学科模型和编者操作化。
5. **投资研究中的使用边界**
   - 多元不等于什么都学；
   - 模型多不等于判断好；
   - 交叉验证不能替代对企业事实的核查。
6. **研究回看**
   - 我现在是否只有一把解释问题的锤子？
   - 如果换一个学科看这个企业，结论会改变哪一部分？

### 明确删除或后移的内容

- 将232个模型身份表移到附录，不在第一章长篇解释；
- 将芒格完整生平和思想演变移到人物导读及年表；
- 删除与投资研究无直接关系的过多现代行业类比；
- 不把“格栅”解释成编者独立发明的完整理论体系；
- 删除重复出现的“不是知识数量，而是工具选择”式总结，只保留一次清楚表达。

### 预计产出

- 正文：约 9,000—12,000 字；
- 直接引文：6—10 段；
- 现场案例：2 个以内；
- 模型身份说明：不超过 800 字；
- 附录只提供模型索引，不把模型表塞进连续正文。

## C. 第一章样章验收

两章完成后先不编入全卷，单独交付一份 PDF 和一份可编辑稿，检查：

1. 连续阅读 30 页是否仍然有主线；
2. 原文、译文和编者文字是否一眼可分；
3. 同一材料是否只承担一个主要任务；
4. 是否有任何段落读起来像“自动生成的总结”；
5. 读者能否在不看注释的情况下理解主线，在需要时又能回查来源；
6. 是否真正有助于投资研究，而不是只增加术语和知识量。

只有这两章通过，才批量处理全卷。
