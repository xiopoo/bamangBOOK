# 典藏层 · 企业索引 {#buffett-index-companies}

按章节出现顺序与字母序交叉组织；每一条目给出：**核心角色 / 出现章节 / 主要思想命题 / 对应观点原子 / 对照案例**。

## A
### 阿勒格尼（Allegheny）
- 角色：伯克希尔保险集群成员；补充浮存金来源与承保纪律案例。
- 章节：CH12 浮存金、CH15 资产结构顶层。
- 命题：伯克希尔保险集群不是单一公司，而是多家在同一标准下运行的组合。
- 观点原子：BA-021、BA-022。

### 美国运通（American Express）
- 角色：巴菲特长期主要公开持仓之一。
- 章节：CH14 组合仓位、CH15 第一层公开组合。
- 命题：高 ROIC、长期品牌信任、客户习惯与转换成本的综合体现。
- 观点原子：BA-008、BA-017。

### 苹果公司（Apple）
- 角色：伯克希尔公开组合第一大持仓之一。
- 章节：CH14 组合结构、CH15 第一层公开组合。
- 命题：品牌与生态转换成本、回购增厚每股权益，都是第十一章"回购价格纪律"的现实案例。
- 观点原子：BA-015、BA-008。

## B
### 伯克希尔·哈撒韦（Berkshire Hathaway）（纺织前身 & 控股公司）
- 角色：全书的制度容器与思想容器。
- 章节：CH05（纺织业务前身，反例）、CH09（组织制度）、CH15（可传承复利制度）。
- 核心命题：伯克希尔不是"一家大公司"，而是由三层结构（保险资金 → 经营企业 → 公开组合+现金）+ 分权文化 + 声誉红线 + 长期资本配置机制共同构成的复利系统。
- 观点原子：BA-011、BA-012、BA-023、BA-024、BA-025、BA-028。
- 对照案例：纺织业务前身（反例） vs 后来的保险/经营/组合三层（正例）。

### BHE（伯克希尔哈撒韦能源，Berkshire Hathaway Energy）
- 角色：伯克希尔中层"重资产但稳定回报"的经营企业代表。
- 章节：CH15 资产结构剖面（中层经营企业）。
- 命题：重资产不一定是坏资产；正确的监管结构、稳定回报、合理进入壁垒下的长期资本，可以是稳定现金流层。
- 观点原子：BA-008、BA-014。

### BNSF（伯灵顿北方圣太菲铁路）
- 角色：伯克希尔中层经营企业中的长周期稳定现金流代表。
- 章节：CH09（10 家子公司业务之一"铁路"）、CH15 中层经营企业。
- 命题：规模、网络、准入壁垒构成的护城河；稳定现金流回流总部用于跨企业再配置。
- 观点原子：BA-008、BA-013。

## C
### 可口可乐（Coca-Cola）
- 角色：巴菲特长期品牌护城河代表持仓。
- 章节：CH06（喜诗对照案例）、CH07（护城河品牌与定价权）、CH15 公开组合。
- 命题：全球品牌 + 客户习惯 + 低增量资本需求，是"长期高 ROIC 不被竞争侵蚀"的经典。
- 观点原子：BA-007、BA-008、BA-017。

## G
### 通用再保险（General Re / Gen Re）
- 角色：伯克希尔再保险板块成员。
- 章节：CH12 浮存金、CH13 风险与巨灾压力测试。
- 命题：再保险的浮存金规模与风险尾部共存；只有定价纪律和准备金严格才能让它是优势。
- 观点原子：BA-021、BA-022、BA-018。

### GEICO（政府雇员保险公司）
- 角色：低成本保险护城河 + 长期浮存金来源的核心案例。
- 章节：CH07（低成本结构护城河）、CH12（浮存金）、CH15（顶层保险资金）。
- 命题：低成本 + 直销渠道 + 承保纪律，让 GEICO 成为伯克希尔保险集群中最稳定、成本最低的资金来源之一。
- 观点原子：BA-008、BA-021、BA-022。

### 好市多（Costco）
- 角色：低成本结构与客户习惯的对照案例（护城河 CH07）。
- 章节：CH07 低成本结构。
- 命题：成本领先可以不是"便宜货"，而是系统性效率和规模带来的对客户/供应商的双向议价权。
- 观点原子：BA-008。

## K
### 卡夫亨氏（Kraft Heinz）
- 角色：公开组合中的品牌与消费品集群案例。
- 章节：CH15 第一层公开组合。
- 命题：品牌强不代表任何价格都值得；整合与价格纪律同样决定结果。
- 观点原子：BA-008、BA-016。

## M
### 穆迪公司（Moody's）
- 角色：公开组合中高 ROIC、转换成本与网络效应的典型。
- 章节：CH07 网络效应/规模、CH15 公开组合。
- 观点原子：BA-008、BA-017。

## N
### 国民赔偿保险公司（National Indemnity, NICO）
- 角色：伯克希尔保险板块基石。
- 章节：CH12 浮存金（先收保费→后赔付的结构示例）。
- 命题：承保纪律决定浮存金真实成本。
- 观点原子：BA-021、BA-022。

### 内布拉斯加家具城（NFM / Nebraska Furniture Mart）
- 角色：管理能力三角 + 低成本护城河的交叉正面案例。
- 章节：CH06（喜诗对照）、CH08（布卢姆金家族 / 经理人三角）。
- 命题："低价格 + 诚实经营 + 家族全心投入 + 长期低费用率"构成不可替代的护城河。
- 观点原子：BA-008、BA-009、BA-010。

## S
### 斯科特费泽（Scott Fetzer）
- 角色：第三章"所有者收益"公式提出的典型企业对照；第十一章收购六项标准的早期成功代表。
- 章节：CH03 会计→所有者收益、CH11 收购标准。
- 附录档案：`appendices/附录A_斯科特费泽ON会计桥完整档案.md`
- 观点原子：BA-002、BA-016。

### 所罗门兄弟（Salomon Brothers）
- 角色：声誉红线教训的反面核心案例。
- 章节：CH09 声誉与去中心化。
- 命题：商业失误可以容忍，品行问题（对监管撒谎、违法违规）容忍度为零。
- 观点原子：BA-011、BA-012。

### 喜诗糖果（See's Candies）
- 角色：全卷最重要的思想转折案例。
- 章节：CH06 全章（核心）、CH10（现金释放）、CH07（品牌护城河对照）。
- 命题：合理价格购买伟大企业；定价权、低增量资本需求、自由现金回流整个系统。
- 对照案例：伯克希尔纺织（第五章）。
- 观点原子：BA-007、BA-008、BA-013。
