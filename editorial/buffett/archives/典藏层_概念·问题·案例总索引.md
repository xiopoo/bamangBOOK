## 三、案例索引 {#buffett-index-cases}

按"案例的教学用途"（正例 / 反例 / 思想演变例 / 边界例）分组。

### A. 正例（这套方法应当如何做）

| 案例 | 章节 | 教学点 | 对照反例 |
| --- | --- | --- | --- |
| 喜诗糖果（See's） | CH06、CH10 | 合理价格买伟大企业；低增量资本 → 自由现金 → 扩展整个系统机会集 | 伯克希尔纺织（CH05） |
| GEICO（低成本保险） | CH07、CH12、CH15 | 护城河"低成本结构"+ 承保纪律 + 长期浮存金来源 | 定价纪律松弛的保险企业 |
| 可口可乐（品牌护城河） | CH07、CH15 | 品牌+客户习惯+低增量资本的长期组合 | 无护城河的包装食品"品牌" |
| 华盛顿邮报（所有者协同） | CH01、CH11 | 深度理解 → 低价 → 重仓 → 长期复利持有 | 不懂的媒体股跟风买入 |
| NFM / 布卢姆金家族 | CH06、CH08 | 管理者三角全满；家族诚实投入 = 长期护城河 | 明星经理人带偏的零售案例 |
| 伯克希尔组织制度（小总部） | CH09、CH15 | 去中心化、信任、共同边界三者协同 | 大总部 + 层层审批的官僚企业 |
| BNSF / BHE | CH15 | 重资产也能是稳定现金流层；正确监管结构和准入壁垒下的好企业 | 需求端被永久替代的重资产陷阱 |
| 2008 金融危机中的逆向行动 | CH13、CH14 | 悲观是朋友；现金储备 + 声誉 = 行动选择权 | 现金枯竭/被迫卖出的 2008 反例 |

### D. 边界例（适用/不适用的边界）

| 边界 | 案例/章节 | 命题 |
| --- | --- | --- |
| 烟蒂法在特定场景下仍然有效（清算/明确催化/极端低价） | CH05 末尾、附录C | 第五章反对的是"无止境投入的低质量生意"，不是所有便宜 |
| 永久持有与定期复核的边界 | CH06、CH11 | 持有是结果，不是口号；四类卖出信号一旦出现必须进入复核 |

| 浮存金适用/不适用的边界 | CH12 | 只有在承保纪律、巨灾准备、资产负债匹配同时满足时才是优势 |

2. **排版索引生成器**：最终目录与索引排版阶段，按本文件的条目和 `#buffett-*` 锚点自动补全页码。
3. **编辑一致性检查器**：任何概念、问题、案例在正文中有定义，就必须对应至少一条索引条目；反之亦然。
