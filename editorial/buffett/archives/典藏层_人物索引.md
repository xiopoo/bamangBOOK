# 典藏层 · 人物索引 {#buffett-index-people}

按姓氏/拼音序排列。索引的目标是"翻到这个人，就能找到他在哪一章、承担了什么角色、对应哪些观点原子"，不重复正文内容。

## 本杰明·格雷厄姆（Benjamin Graham）
- 角色：巴菲特的老师，价值投资传统的开创者；"烟蒂""安全边际""市场先生"等概念来源。
- 出现章节：CH01（市场先生/所有者视角）、CH04（安全边际与早期方法）、CH05（烟蒂法及其边界）。
- 核心命题：市场价格是交易条件而非价值本身；以资产折价与分散抵御无知；但在"高质量企业"问题上留下的缺口，由巴菲特和芒格后来补上。
- 对应观点原子：BA-001、BA-005、BA-026。
- 扩展阅读入口：`content/partnership/*` 合伙人信中对早期方法的逐次表达。

## 查理·芒格（Charlie Munger）
- 角色：伯克希尔副董事长；巴菲特方法的"第二作者"；推动从"便宜资产"走向"合理价格买伟大企业"的关键转折。
- 出现章节：CH06（喜诗转折）、CH08（经理人三角）、CH11（持有期限澄清）、CH15（可传承思想）。
- 核心命题：**好企业 + 好管理 + 好价格 + 长期** 是四合一，不可以只拿"任何价格买伟大企业"作口号；永久持有是倾向不是契约。
- 对应观点原子：BA-007、BA-008、BA-010、BA-017。
- 常见误读：因为芒格经常说"长期"，所以任何情况都不卖——正文中多次澄清：复核与卖出条件仍然成立。

## 沃伦·巴菲特（Warren E. Buffett）
- 角色：伯克希尔董事长；全书思想与制度的第一构建者与实践者。
- 出现章节：全卷十五章均以其思想和制度为核心对象，但不采用"传记式叙述"，而是以企业部分所有权—资本配置—制度传承的闭环组织。
- 关键命题：
  - 思维起点：所有者身份（CH01/15 回环）
  - 衡量核心：所有者收益与内在价值（CH02/03）
  - 方法转折：便宜资产→优质企业（CH05/06）
  - 组织系统：极小总部 + 分权 + 声誉红线（CH08/09）
  - 配置工具：再投资/收购/回购/分红/现金（CH10-12）
  - 风险与传承：购买力风险、现金准备、可传承制度（CH13-15）
- 对应观点原子：BA-001 ~ BA-028 全 28 个观点原子。
- 读者应当注意：全书以"方法和系统"为主，不是巴菲特传记或语录汇编。

## 布卢姆金家族（Blumkin Family, B夫人 / NFM）
- 角色：内布拉斯加家具城（NFM）创始人与家族经营者；管理能力三角的正面案例。
- 出现章节：CH08 选择经理人。
- 核心命题：能力 + 精力 + 正直三角全满的典型。制度不需要"超级明星"，但对的人能放大制度的效果。
- 对应观点原子：BA-009、BA-010。

## 凯瑟琳·格雷厄姆（Katharine Graham）
- 角色：华盛顿邮报出版人；巴菲特早期重要投资对象与治理合作案例。
- 出现章节：CH09（信任与声誉）、CH11（长期持有的典型）。
- 核心命题：好的所有者 + 好的经营者 + 好的行业结构 = 长期复利协同。
- 对应观点原子：BA-001、BA-017。

## 阿吉特·贾恩（Ajit Jain）
- 角色：伯克希尔再保险负责人；保险业务与承保纪律的关键管理者。
- 出现章节：CH12 浮存金。
- 核心命题：浮存金质量的最终保证人不是规模，而是定价纪律、巨灾准备和长期理性。
- 对应观点原子：BA-021、BA-022。

## 格雷格·阿贝尔（Greg Abel）
- 角色：伯克希尔现任副董事长（非保险），负责经营业务板块及能源 BHE 等；接班框架中的关键人物。
- 出现章节：CH09（分权与制度）、CH15（可传承制度）。
- 核心命题：组织可传承不是换个明星 CEO，而是"制度+声誉+文化+资本配置方法"整套一起传。
- 对应观点原子：BA-011、BA-023、BA-028。

## 托德·库姆斯（Todd Combs） & 泰德·韦施勒（Ted Weschler）
- 角色：伯克希尔投资经理；管理集团旗下部分公开组合与交易执行。
- 出现章节：CH09（小总部与授权）、CH15（投资能力传承）。
- 核心命题：制度要能"吸收后来者"，不把一切能力都绑在创始人身上。
- 对应观点原子：BA-009、BA-023、BA-028。

## 梅奥诊所（Mayo Clinic）（组织/人物对照案例）
- 角色：不是单个人物，而是"不依赖英雄的优秀组织"案例，用于经理人三角。
- 出现章节：CH08 选择经理人。
- 核心命题："如果一家企业需要超级明星才能取得卓越成果，它本身就不算伟大。"
- 对应观点原子：BA-009。
